# 이어갈래? (ieogallae-proto)

연말 약속 날짜를 조율하는 모바일 웹 서비스 **이어갈래?** 의 프로토타입 저장소야.

- 가입 없이 링크 하나로 친구들을 초대해
- 참여자는 달력 캡처를 올리면 AI가 가능/불가 날짜를 자동으로 분류해 (프로토타입에서는 가짜 로딩으로 처리)
- 전원이 답하지 않아도 응답자가 70%를 넘으면 날짜 Top3(잠정 결과)가 공개돼
- 늦게 온 사람은 Top3 중 되는 날만 체크하면 돼

## 저장소 구성

| 경로 | 내용 |
| --- | --- |
| [`spec.md`](spec.md) | 화면 명세(IA v2). 서비스 개요, 디자인 규칙, 샘플 데이터, 상태 로직, 데모 컨트롤 패널, 전체 화면 목록 |
| [`wireframes/`](wireframes/) | 로우파이 와이어프레임 원본(`*.dc.html`). 레이아웃과 문구의 기준 |

와이어프레임 파일은 다음과 같이 나뉘어 있어.

- `A-create.dc.html`: 진입(L0)과 약속 만들기(A1~A4)
- `B-respond-1.dc.html`, `B-respond-2.dc.html`: 응답하기(B1~B6)
- `C-status.dc.html`: 현황·결과(C1~C3)
- `D-confirm.dc.html`: 확정·공유(D1~D2)

## 실행 방법

아직 앱 코드는 없고, 기획 문서와 와이어프레임만 있는 단계야.

- **명세 보기**: `spec.md`를 GitHub이나 마크다운 뷰어에서 열면 돼.
- **와이어프레임 보기**: `wireframes/*.dc.html`은 전용 런타임(`support.js`)용 파일이라 브라우저에서 바로 열면 제대로 보이지 않아. 텍스트 에디터로 마크업을 열어서 화면 구조와 문구를 참고해줘.

프로토타입 코드가 추가되면 이 섹션에 설치와 실행 명령을 적을 예정이야.
